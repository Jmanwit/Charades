Charades Time

A simple family charades game that runs as a web app.

INSTALLING CHARADES LIKE AN APP

Android (Chrome):

1. Open the Charades Time website in Chrome:
   https://jmanwit.github.io/Charades/

2. Look for the Install icon near the address bar.

3. Tap it, then choose Install.

4. Charades Time will now appear in your app list and can also be placed on your Home screen.

5. If you already installed an older version, uninstall the old Charades Time app first and reinstall it from the website so the new app icon is used.


iPhone / iPad (Safari):

1. Open the Charades Time website in Safari:
   https://jmanwit.github.io/Charades/

2. Tap the Share button (the square with the upward arrow).

3. Scroll down and tap "Add to Home Screen."

4. Confirm the name and tap "Add."

5. Charades Time will appear on the Home screen like an app.


IMPORTANT:

Each device keeps its own players, scores, and card history.

Installing Charades Time on another phone or tablet does not share game data between devices.

For example, the tablet can have one set of players and game history while a phone has completely separate game data.


FEATURES:

- 100 charades cards
- New Card button
- Persistent used-card history across games
- New Card counts as used
- Prevents recently used cards from immediately returning after a full cycle
- End Game confirmation
- Android/browser Back button confirmation
- Installable as a web app on Android and Apple devices
- Custom Charades Time theater-mask app icon
